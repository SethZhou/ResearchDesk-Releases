# ResearchDesk · Windows 下载

[下载联网安装器 ResearchDesk-Setup-Web.exe](https://github.com/SethZhou/ResearchDesk-Releases/releases/latest/download/ResearchDesk-Setup-Web.exe)

只需分享这个约 **3.6 MB** 的文件。双击后按向导选择安装目录和组件，下载、校验、安装会自动完成。支持 Windows 10 / 11 x64，无需预装 Python。

| 组件 | 安装方式 | 下载大小约 |
| --- | --- | --- |
| 主程序及界面字体 | 必选，自动下载 | 352 MB |
| TeX Live 排版环境 | 按勾选下载 | 2.44 GB |
| 本地 AI、离线翻译及句法检查 | 按勾选下载 | 3.72 GB |

首次安装需联网访问 GitHub Releases，进度显示在安装窗口中。安装器会检查磁盘空间并校验下载文件；安装完成后的论文编辑、排版和本地 AI 可离线使用。INSPIRE 文献更新和论文同步需要联网。

内置演示项目的作者、正文、数据、图表和参考文献均为虚构。演示文献只在示例项目中使用，打开、编辑示例或单独导入示例 Bib 都不会把它们加入个人文献库。

可以从 Windows“设置 → 应用”卸载。默认保留个人文献库、账户配置、恢复草稿和论文工作副本。选择彻底清除后还需二次确认，确认按钮等待 **10 秒**才可点击。
