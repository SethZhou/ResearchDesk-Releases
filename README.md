# ResearchDesk

让科研与写作，自然相连。

ResearchDesk 是面向科研写作的 Windows 桌面工作台，将 LaTeX 论文写作、文献管理、引用检索与翻译整合在一起。

## 开始使用

下载小型安装器，选择安装目录，再按需勾选 TeX Live 和本地 AI。安装器自动选择下载线路，并复用已下载且校验通过的组件。已有用户可在设置中点击“检查更新”。

## 主要功能

- **论文写作**：LaTeX 编辑与 PDF 预览，独立管理多个论文项目。
- **文献管理**：分类、检索、PDF 与 BibTeX 集中管理，支持 INSPIRE 引用检索与更新。
- **翻译辅助**：支持本地离线翻译，也可自行配置云端 API。
- **数据随身带**：论文、文献及账户设置统一保存在“个人数据”文件夹，关闭软件后可整体备份或迁移。

当前正式版：**1.0.19**。程序更新保留个人数据、TeX Live 和本地 AI 模型。
